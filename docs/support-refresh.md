# 지원정책 수집 스케줄

`YouthSupportScheduler`의 첫 실행 지연을 환경변수로 설정한다.

```dotenv
# 밀리초 단위. 예: 60,000ms = 1분 후 첫 실행
SUPPORT_REFRESH_INITIAL_DELAY_MS=60000
```

- 기본값은 `0`이며, 기존처럼 스케줄러가 활성화되면 바로 실행한다.
- 매번 애플리케이션이 시작될 때 초기 지연이 적용된다.
- 이후 주기는 이전 작업이 끝난 시점부터 3일(`fixedDelay`)로 유지한다.
- 정책 원본 목록과 건수의 Redis TTL은 10일이다.
- 추천용 정책 점수 캐시 TTL은 4일이며, 수집 작업 종료 시 해당 점수 캐시를 삭제한다.
- 최초 지연 설정은 데이터 TTL이나 이후 실행 간격을 바꾸지 않는다.

Spring 설정 키는 `support.refresh.initial-delay-ms`이다.
환경변수를 수정했다면 변경값을 전달한 새 프로세스/컨테이너로 시작해야 한다.
